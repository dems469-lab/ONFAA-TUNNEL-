# `gradle/` — Outillage Gradle (préparé)

Ce répertoire est réservé aux éléments liés à Gradle (ex. wrapper, catalogues de versions, conventions) lorsque le projet Android sera initialisé.

## État Phase 0

- Aucun fichier Gradle n’est ajouté en Phase 0 afin de ne pas introduire de configuration de build incomplète ou trompeuse.
- L’introduction du wrapper et des scripts de build est prévue avec les **fondations Android (Phase 1)** et sera alignée avec la stratégie de compilation sur **GitHub Actions (Phase 9)**.
