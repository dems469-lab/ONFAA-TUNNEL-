# Références — Composants

**Aucune planche de composants isolée n’a été fournie.**

Les composants réutilisables (cartes, boutons, chips, badges, en-têtes, lignes de
réglage, orbe, graphique, lignes de journal) ont été extraits des cinq écrans complets
et implémentés dans `app/src/main/java/com/onfaa/tunnel/ui/components/`.

Voir `../README.md` et `../../DESIGN_SPEC.md` pour le catalogue et les états.
