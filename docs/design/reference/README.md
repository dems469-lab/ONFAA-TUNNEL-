# Références visuelles (design)

Ce dossier est réservé aux images de référence (maquettes, captures, inspirations) fournies ultérieurement pour ONFAA TUNNEL.

## État actuel

- **Aucune image de référence n’est présente dans le dépôt.**
- Les spécifications fonctionnelles et thématiques sont décrites dans [`../DESIGN_SPEC.md`](../DESIGN_SPEC.md).

## Règles

- Ajouter uniquement des fichiers dont la diffusion dans le dépôt est autorisée.
- Ne pas inclure de captures contenant des configurations personnelles, UUID, clés, adresses sensibles ou informations privées.
- Lors de l’ajout d’images, mettre à jour ce README avec la liste des fichiers et leur rôle (écran/thème concerné).
